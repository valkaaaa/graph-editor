# Changelog

Все значимые изменения в проекте GraphEditor Pro.

## [1.6.0] - 14.11.2026

### Добавлено
- **Символьная математика (SymPy):** упрощение формул, производные и интегралы в один клик.
- **Локальный ИИ-помощник:** генерация формул по текстовому описанию через Ollama или LM Studio.
- **3D-генератор:** возможность строить поверхности `z = f(x, y)` и 3D-параметрические кривые `x(t), y(t), z(t)`.
- **Поддержка переменных в формулах:** автоматическое создание ползунков для параметров `a, b, c...` и поддержка жестких констант через `a=5`.
- **Комплексные числа:** поддержка `1j`, `real()`, `imag()`, `abs()`, `angle()` в формулах.
- **DSL-консоль:** текстовый интерфейс для быстрого построения графиков командами.
- **Обработка сигналов:** фильтр Савицкого-Голея, интерполяция (linear/cubic/pchip), поиск производных и интегралов.
- **Плагины:** поддержка создания пользовательских анимаций, тем и шаблонов (добавлен пример с 3D-маятником).
- **Инструменты холста:** линейка для измерения расстояний, выделение прямоугольником (с возможностью сохранить в CSV), настройка Z-order слоев и группировка объектов.
- **UI:** вкладки теперь имеют прокрутку, добавлен справочник формул, исправлен статусбар и вставка через `Ctrl+V`.

### Исправлено
- Бесконечный цикл при восстановлении автосохранения.
- Отсутствие проверки типов данных в аппроксимации (теперь `_add_fit` не падает на строках).
- Перекрытие статусбара нижней панелью инструментов.
- Конфликты глобальных горячих клавиш с полями ввода.
