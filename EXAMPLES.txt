# GraphEditor Pro — примеры данных для типов графиков
================================================================================

Формат: значения вводятся как числа через запятую (,), пробел или точку с запятой.
Группы (для box plot, violin и т.п.) — через ";".
Матрицы (для Heatmap, Contour, Chord, Дендрограмма и т.п.) — строки через ";",
внутри строки — числа через запятую.

Дополнительные поля:
  X — данные по оси X или метки категорий через запятую
  Y — данные по оси Y, группы через ";" или значения
  Z — третья ось, матрица или формула
  Yerr (Погрешности Y) — погрешности (error bars) или компоненты (Quiver)
  Pie labels (Подписи) — текстовые подписи через запятую
  Pie colors (Цвета) — HEX-цвета или имена через запятую (red, blue, #ff8800)
  Treemap parents (Родители) — через ";", пустые = корень
  Bins (Бины/параметр) — целое число, смысл зависит от типа

================================================================================
  СОВЕТЫ
================================================================================

1. Для большинства типов работает Ctrl+V из Excel (вставляет колонки).
2. Для матриц (Heatmap, Chord, Дендрограмма) используйте кнопку «Таблица».
3. Формулы в генераторе можно комбинировать через «;» — построится
   несколько линий с разными цветами.
4. Для Q-Q plot, ECDF, Recurrence, Poincaré достаточно одного Y.
5. Свечи (OHLC) — 4 серии в Y через «;» в порядке Open;High;Low;Close.
6. Sankey принимает только положительные (отрицательные берутся по модулю).
7. Stream plot — две матрицы: U в Z, V в Погрешностях Y.
8. Дендрограмма/Chord/Adjacency — квадратные или прямоугольные матрицы.
9. Bode: X — частота (лог. ось), Y — дБ, Z — фаза (опционально).
10. Smith: X/Y — Re/Im, либо Z-матрица 2×N.
11. Riemann surface: Z — формула от z (комплексного), например sqrt(z).
12. Radial tree 3D: X — z_offset (одно число, обычно 0.2–1.0).
13. Диаграмма Тейлора: X — reference std (одно число), Z — 2 строки.
14. Сосулька: X — родители через «;», пустые = корневые.
